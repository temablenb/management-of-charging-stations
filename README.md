# Мультиагентная система распределения электроэнергии между зарядными станциями

Имитационная модель сети зарядных станций электромобилей, в которой распределением мощности занимаются не один центральный модуль, а несколько самостоятельных агентов, обменивающихся сообщениями.

**Цель:** оптимизировать распределение электроэнергии между станциями, снизить затраты на зарядку и обеспечить стабильность работы сети (отсутствие превышений лимита подстанции).

**Статус:** проект в разработке. Сейчас реализован прототип на Streamlit (мониторинг, прогноз Хольта–Винтерса, оптимизация мощности линейным программированием, личный кабинет). Мультиагентное ядро и имитационная модель добавляются поэтапно.

## Агенты

| Агент | Роль |
| --- | --- |
| Grid Agent (GA) | Знает лимит подстанции, получает запросы мощности от станций, распределяет мощность между ними и задаёт тарифный множитель |
| Station Agent (SA) | Управляет одной станцией: ведёт очередь автомобилей, строит план зарядки, прогнозирует свою нагрузку и запрашивает мощность у Grid Agent |
| Electric Vehicle Agent (EVA) | Представляет автомобиль: сообщает станции, сколько энергии нужно и к какому времени, и реагирует на тариф |
| Energy Storage Agent (ESA) | Накопитель энергии: заряжается в часы низкого тарифа и отдаёт энергию в сеть в пик, разгружая подстанцию |

## Обмен сообщениями

1. EVA отправляет Station Agent заявку: нужный объём энергии, желаемое время завершения, максимальная мощность зарядки.
2. SA собирает заявки, формирует очередь и план зарядки и передаёт Grid Agent суммарную потребность вместе с прогнозом нагрузки на ближайшие часы.
3. GA сопоставляет запросы всех станций с лимитом подстанции и резервом накопителя, решает задачу распределения мощности и отправляет каждой станции выделенное значение.
4. SA пересчитывает план зарядки. Если выделенной мощности не хватает на всех, очередь корректируется с учётом приоритетов (время ожидания, предоплата).
5. GA формирует тариф станции: базовая цена умножается на множитель, который растёт при высокой нагрузке и падает при низкой.

## Запуск в Docker

Требуются Docker и Docker Compose.

```bash
git clone https://github.com/temablenb/management-of-charging-stations.git
cd management-of-charging-stations
docker compose up --build
```

Интерфейс открывается на http://localhost:8501.
База данных хранится в папке `data/` и сохраняется между перезапусками.
Остановка: `docker compose down`.
